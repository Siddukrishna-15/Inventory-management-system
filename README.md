# 📦 Inventory Management System

## 📖 Overview

The **Inventory Management System** is a full-stack web application designed to simplify inventory tracking and management. The application provides secure **Login/Register** functionality and allows users to manage inventory items through the **InventoryHub** dashboard.

Users can add and manage product details such as **Item Name, Category, Quantity, Price, and Total Value**. The dashboard provides clear inventory insights with status cards for **Low Stock, Available Items, and Total Inventory Value**, along with a **Pie Chart** for better data visualization.

The project is developed using **HTML, CSS, JavaScript** for the frontend and **Node.js with Express.js** for the backend, with database integration for managing inventory data.

---

## 🚀 Features

* User Login and Registration system
* Secure authentication handling
* Add and manage inventory items
* Track item name, category, quantity, and price
* Automatic total value calculation
* Dashboard with inventory statistics
* Low stock and availability status tracking
* Pie chart for inventory data visualization
* Responsive and user-friendly interface
* Backend API integration

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/Siddukrishna-15/inventory-management-system.git
```

### Step 2: Navigate to Backend Folder

```bash
cd Backend
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Backend Server

```bash
node server.js
```

### Step 5: Run the Frontend

Open `login.html` in your browser and register/login to access the InventoryHub dashboard.
